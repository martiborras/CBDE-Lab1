C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Same fixed dataset used throughout the experiments

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Documents were inserted into Chroma using batch insertion.
- Batch size: 1 document.
- Chroma's default embedding function was used:
  all-MiniLM-L6-v2
- The embedding model was warmed up before measurements.
- The warm-up time was therefore excluded from the measurements.
- The Chroma collection was recreated empty before the experiment.
- Each document was inserted individually and its insertion time was
  measured separately.

Results:
- Inserted sentences: 10,000
- Number of batches: 10,000
- Batch size: 1

Timing:
- Minimum batch insertion time: 0.197316 s
- Maximum batch insertion time: 1.151029 s
- Average batch insertion time: 0.278893 s
- Standard deviation: 0.036066 s

Observation:
- Individual insertion was substantially slower than the larger batch
  configurations tested later.
- This experiment provides the baseline for the batch-size comparison.
- The total execution time was not measured by the original version of
  the program, so it is not reported here.
