C1 — Chroma embedding storage experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Embedding model: all-MiniLM-L6-v2
- Embedding dimensions: 384

Environment:
- Ubuntu 24.04 LTS through WSL2
- Python 3.12
- ChromaDB 1.5.9

Methodology:
- The embedding model was loaded before the experiment.
- The model was warmed up before timing measurements.
- An embedding was explicitly generated for each sentence.
- The generated embedding was then passed to Chroma together with the
  corresponding document.
- Embedding generation time and embedding storage time were measured
  separately.
- The storage measurement therefore includes the Chroma collection.add()
  operation using the precomputed embedding.

Results:
- Stored sentences: 10,000

Embedding generation timing:
- Minimum: 0.008328 s
- Maximum: 0.338530 s
- Average: 0.011261 s
- Standard deviation: 0.004840 s

Embedding storage timing:
- Minimum: 0.013158 s
- Maximum: 0.564880 s
- Average: 0.030485 s
- Standard deviation: 0.015048 s

Observation:
- The average embedding generation time was approximately 11.26 ms
  per sentence.
- The average embedding storage time was approximately 30.49 ms
  per sentence.
- Embedding generation and storage were measured separately.
