C0 — Chroma individual insertion baseline

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000

Environment:
- Windows host + WSL2
- Ubuntu 24.04
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Same dataset and sentence split as PostgreSQL P0.
- One Chroma add() operation per sentence.
- Default Chroma embedding function:
  all-MiniLM-L6-v2
- Persistent Chroma storage.

Important:
Unlike PostgreSQL P0, this experiment includes both:
- embedding generation
- vector persistence

Results:

Inserted sentences: 10000

Minimum insertion time: 0.197316 s
Maximum insertion time: 1.151029 s
Average insertion time: 0.278893 s
Standard deviation: 0.036066 s
