C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Batch size: 5000 documents.
- Default Chroma embedding function: all-MiniLM-L6-v2.
- Embedding model warmed up before measurements.
- Collection recreated empty before each execution.
- 10,000 documents were inserted in 2 batches.

Execution 1:
- Inserted sentences: 10,000
- Batches: 2
- Total execution time: 527.135777 s
- Average time per sentence: 0.052714 s
- Minimum batch insertion time: 261.468054 s
- Maximum batch insertion time: 265.646822 s
- Average batch insertion time: 263.557438 s
- Standard deviation: 2.954835 s

Execution 2:
- Inserted sentences: 10,000
- Batches: 2
- Total execution time: 520.840637 s
- Average time per sentence: 0.052084 s
- Minimum batch insertion time: 259.367465 s
- Maximum batch insertion time: 261.445993 s
- Average batch insertion time: 260.406729 s
- Standard deviation: 1.469741 s

Observation:
- The two executions produced very similar results.
- Increasing the batch size to 5000 did not cause a clear degradation
  in total execution time.
- The results remain in the same performance range as batch sizes
  between approximately 750 and 2000.
