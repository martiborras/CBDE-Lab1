C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Batch size: 1250 documents.
- Default Chroma embedding function: all-MiniLM-L6-v2.
- Embedding model warmed up before measurements.
- Collection recreated empty before the experiment.
- 10,000 documents were inserted in 8 batches.

Results:
- Inserted sentences: 10,000
- Batches: 8
- Batch size: 1250
- Total execution time: 528.652782 s
- Average time per sentence: 0.052865 s
- Minimum batch insertion time: 65.192864 s
- Maximum batch insertion time: 68.511436 s
- Average batch insertion time: 66.079345 s
- Standard deviation: 1.037574 s

Observation:
- The result was in the same performance range as the 750 and 1000
  experiments.
- No clear degradation was observed at batch size 1250.
