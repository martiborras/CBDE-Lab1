C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Same fixed dataset used throughout the experiments

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Documents were inserted into Chroma using batch insertion.
- Batch size: 500 documents.
- Chroma's default embedding function was used:
  all-MiniLM-L6-v2
- The embedding model was warmed up before measurements.
- The warm-up time was therefore excluded from the experiment.
- The Chroma collection was recreated empty before the experiment.
- The measured total execution time includes embedding generation and
  insertion/persistence of the 10,000 documents.

Results:
- Inserted sentences: 10,000
- Number of batches: 20
- Batch size: 500

Timing:
- Total execution time: 543.747450 s
- Total execution time: approximately 9 min 04 s
- Average time per sentence: 0.054375 s
- Minimum batch insertion time: 23.840362 s
- Maximum batch insertion time: 28.560626 s
- Average batch insertion time: 27.186096 s
- Standard deviation: 0.943170 s

Observation:
- Increasing the batch size from 250 to 500 reduced the total execution
  time from 582.156742 s to 543.747450 s.
- This represents an improvement of approximately 6.6%.
- The improvement is smaller than the improvement obtained with the
  earlier increases in batch size.
- Further experiments with larger batch sizes will be used to determine
  whether the performance continues to improve or starts to degrade.
