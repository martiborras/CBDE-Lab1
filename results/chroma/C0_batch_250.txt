C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Same fixed dataset used throughout the experiments

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Documents were inserted into Chroma using batch insertion.
- Batch size: 250 documents.
- Chroma's default embedding function was used:
  all-MiniLM-L6-v2
- The embedding model was warmed up before measurements.
- The warm-up time was therefore excluded from the experiment.
- The Chroma collection was recreated empty before the experiment.
- The measured total execution time includes embedding generation and
  insertion/persistence of the 10,000 documents.

Results:
- Inserted sentences: 10,000
- Number of batches: 40
- Batch size: 250

Timing:
- Total execution time: 582.156742 s
- Total execution time: approximately 9 min 42 s
- Average time per sentence: 0.058216 s
- Minimum batch insertion time: 12.773137 s
- Maximum batch insertion time: 16.067792 s
- Average batch insertion time: 14.553187 s
- Standard deviation: 0.589591 s

Observation:
- Increasing the batch size from 100 to 250 reduced the total execution
  time from approximately 10.7 minutes to 9.7 minutes.
- The improvement is smaller than the improvement obtained when moving
  from individual insertion to batch insertion.
- Further experiments with larger batch sizes (500, 750 and 1000) will
  be performed to study whether the execution time continues to decrease.
