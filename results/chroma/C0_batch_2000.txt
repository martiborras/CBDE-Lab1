C0 — Chroma batch insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- ChromaDB 1.5.9

Methodology:
- Batch size: 2000 documents.
- Default Chroma embedding function: all-MiniLM-L6-v2.
- Embedding model warmed up before measurements.
- Collection recreated empty before the experiment.
- 10,000 documents were inserted in 5 batches.

Results:
- Inserted sentences: 10,000
- Batches: 5
- Batch size: 2000
- Total execution time: 535.328957 s
- Average time per sentence: 0.053533 s
- Minimum batch insertion time: 105.905918 s
- Maximum batch insertion time: 110.081655 s
- Average batch insertion time: 107.061582 s
- Standard deviation: 1.707690 s

Observation:
- Increasing the batch size to 2000 did not produce a significant
  improvement compared with the smaller large-batch configurations.
- The result remained in the same general performance range.
