P0 — PostgreSQL text insertion
Machine: Bernat

Environment:
- Windows host + WSL2
- Ubuntu 24.04 LTS
- Python 3.12.3
- PostgreSQL 16.15
- Dataset: bookcorpus_10000.csv
- Sentences: 10,000

Methodology:
- Each sentence was inserted individually.
- Each INSERT was followed by an individual COMMIT.
- Timing was measured using time.perf_counter().
- The measured time includes the INSERT and COMMIT.
- The sentences table was truncated before each run.
- Five complete runs were executed on the same machine.
