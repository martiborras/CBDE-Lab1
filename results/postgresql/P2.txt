P2 — PostgreSQL similarity search experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Embedding model: all-MiniLM-L6-v2
- Embedding dimensions: 384

Environment:
- Ubuntu 24.04 LTS through WSL2
- Python 3.12
- PostgreSQL 16

Methodology:
- The experiment uses 10 fixed query sentences distributed across the dataset.
- The same query sentences are used for PostgreSQL P2 and Chroma C2.
- All sentence embeddings were previously stored in PostgreSQL during P1.
- For each query sentence, its embedding was compared against all stored
  embeddings.
- The experiment computes the two closest sentences using Euclidean distance
  and cosine distance.
- Distance calculations and sorting are performed in Python using the
  embeddings retrieved from PostgreSQL.
- Query time measurements include the complete similarity calculation process.

Results:

Euclidean distance:
- Minimum query time: 0.157755 s
- Maximum query time: 0.195107 s
- Average query time: 0.169434 s
- Standard deviation: 0.012877 s

Cosine distance:
- Minimum query time: 0.176101 s
- Maximum query time: 0.183396 s
- Average query time: 0.180597 s
- Standard deviation: 0.002162 s

Observation:
- PostgreSQL stores the embeddings, but the similarity computation is
  performed externally in Python.
- The experiment provides the relational-database baseline for comparison
  with Chroma C2.
