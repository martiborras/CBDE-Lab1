P0 — PostgreSQL text insertion experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Same fixed dataset used throughout the experiments

Environment:
- Ubuntu 24.04 LTS through WSL2
- Python 3.12
- PostgreSQL 16

Methodology:
- The PostgreSQL table was cleared before the experiment.
- The 10,000 sentences were read from the fixed BookCorpus dataset.
- Each sentence was inserted individually.
- Each INSERT was followed by an individual COMMIT.
- Timing was measured using time.perf_counter().
- The measured time includes the INSERT operation and its corresponding
  transaction commit.
- The insertion time was measured separately for each sentence.

Results:
- Inserted sentences: 10,000

Timing:
- Minimum insertion time: 0.000868 s
- Maximum insertion time: 0.034018 s
- Average insertion time: 0.001391 s
- Standard deviation: 0.000659 s

Observation:
- The experiment provides the PostgreSQL baseline for individual
  sentence insertion.
- The average insertion time was approximately 1.39 ms per sentence.
- The maximum insertion time was 34.018 ms.
