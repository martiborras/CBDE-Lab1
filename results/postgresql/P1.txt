P1 — PostgreSQL embedding storage experiment

Dataset:
- File: data/bookcorpus_10000.csv
- Sentences: 10,000
- Embedding model: all-MiniLM-L6-v2
- Embedding dimensions: 384

Environment:
- Ubuntu 24.04 LTS through WSL2
- Python 3.12
- PostgreSQL 16

Methodology:
- The 10,000 sentences were already stored in PostgreSQL from P0.
- The embedding model was loaded before the experiment.
- An embedding was generated for each sentence before starting the timing measurement.
- The generated embedding was stored in the existing sentence row.
- Each embedding was stored using an UPDATE operation followed by an individual COMMIT.
- The measured time therefore includes only the PostgreSQL storage operation
  and its corresponding transaction commit.
- Embedding generation time is not included in the storage measurements.

Results:
- Stored embeddings: 10,000

Storage timing:
- Minimum storage time: 0.002504 s
- Maximum storage time: 0.039036 s
- Average storage time: 0.003435 s
- Standard deviation: 0.000631 s

Observation:
- The average time required to store an embedding was approximately
  3.44 ms per sentence.
- The embedding generation process was performed outside the measured
  storage section.
